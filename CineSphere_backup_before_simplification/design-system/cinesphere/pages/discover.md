# Discover page overrides

Overrides `../MASTER.md` only where stated. The skill's section list for "Search Results" (hero search, categories, "Become a host/seller") is for a marketplace and is not used.

- **Search (skill):** results update as the user types; no need to press Enter.
- **No results (skill):** never a blank screen or "0 results". Show a message, a Clear action, and suggested genres to try.
- **Filters:** every control has a visible label. State lives in the URL so filtered views can be shared and restored.
- **Sorting:** only criteria present in the data are offered (rating appears only once real ratings exist).
